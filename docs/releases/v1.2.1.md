# Spelunk 1.2.1

Spelunk 1.2.1 is a patch release focused on the Spelunk AI panel and renderer responsiveness.

## Highlights

- Added more Spelunk AI binary-navigation tools, including address descriptions, byte dumps, loose data xrefs, disassembly fetches, batch function fetches, and function-with-callees context.
- Improved the Spelunk AI system prompt so answers lean on tools and concrete evidence instead of speculation.
- Reduced UI lag when applying AI rename suggestions by coalescing annotation saves and avoiding growing rename-substitution work.
- Improved renderer caching for display names, visible code lines, and AI chat turns.
- Fixed the sidebar brand mark to use the Spelunk mascot instead of the placeholder letter.

## Notes

- Packaged releases currently publish Linux and Windows artifacts. macOS remains covered by CI build checks but is not packaged by the release workflow yet.
