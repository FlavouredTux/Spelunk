# Spelunk 2.0.0

Spelunk 2.0 is the first release since 1.2.2. The project is renamed from
Ember, the Electron app is replaced by a native Qt front end, the decompiler
learns 32-bit x86 and the SSE-to-AVX2 instruction sets, and pseudo-C output
is now checked by recompiling it and running it against the original code.

## Breaking Changes

- Ember is now Spelunk: the CLI is `spelunk`, the GUI `spelunk-gui`, the C++
  namespace `spelunk`, the cache `~/.cache/spelunk` and annotation sidecars
  `<binary>.spelunk-annotations`. CMake targets and options are renamed to
  match.
- The Electron renderer is gone. The desktop front end is a Qt 6 application
  under `gui/`, linked straight against the core library. It is optional;
  build it with `cmake --preset gui`.
- Removed: the built-in debugger (`--debug`), Unreal Kismet bundles
  (`--kismet`), the TEEF recognition pipeline (`--teef`, `--recognize`,
  `--corpus`, `--orbit-dump`), the `spelunkpy` Python wrapper and declarative
  `.spelunk` scripts. Annotation sidecars still work.
- `spelunk --version` prints the version. The DTK config selector that used
  that flag is now `--dtk-version`.

## Decompiler

- 32-bit x86: PE32 images, per-function Win32 calling conventions with
  callee-popped arguments, the full x87 opcode map lifted as a register stack,
  MSVC patterns (SEH frames, `__SEH_prolog4`-style frame helpers, REP string
  copies as `memcpy`/`memset`), Win32 API prototypes and MSVC-aware function
  discovery.
- SIMD: SSE2 through SSE4.2, SSSE3, AES-NI, PCLMUL and CRC32, plus VEX AVX,
  AVX2, FMA3/FMA4, F16C, BMI1/BMI2, ADX and RDRAND. Vector code renders as
  `_mm_*` / `_mm256_*` intrinsics. Functions that hit an undecodable
  instruction went from 260 to 0 in libm and from 100 to 0 in libjpeg.
- Bytes that still cannot be decoded show as `__undecoded(addr)` instead of
  silently dropping the code path behind them.
- `--emit-c` exports compilable C with declarations and explicit memory
  accesses. It is solid on the test corpus and still early on large stripped
  binaries.
- Correctness fixes found by differential testing: loop variables whose
  updates were dropped, merged return values, signed division, NaN compares,
  float conversions, carry chains in multi-word arithmetic, stack frames
  realigned for AVX, and switch tables read past their guard (selectors
  compared in memory, or guarded by a `jbe` into the table's block).
- Functions that never finished now take seconds: stack-pointer phis are
  solved together as one fixpoint instead of by recursion, and phi type
  queries are memoized.
- Loops whose body is only a header render as `do { } while`, and edge copies
  land inside `if`/`else` arms.
- Stripped ELF binaries recover `_start` and `main`, and unwind data sets
  function boundaries.
- Wii U: RPX decompression, import resolution and static relocations;
  better PowerPC virtual-call recovery.

## Performance

- Batch decompilation (`--symbols FILE`) renders functions in parallel with
  ordered output. A full pass over libssl went from 32 s to 2.5 s.

## Command Line

- `--json` emits one record per function, and batches continue past errors.
- `--timeout TIME` sets a whole-command deadline (`250ms`, `10s`, `2m`); a
  timeout exits with 124.
- `scripts/ci.sh` runs the test, clang, release, ASan and fuzz jobs on any
  host. `scripts/ci.sh release` builds, strips and packages the CLI.

## GUI

- A graph view on `Space`: one box per basic block, taken branches green,
  fallthroughs red, other edges blue, loops routed up the side. Drag to pan,
  `Ctrl+wheel` to zoom, `W` to fit the window, `1` for 100%. Renames,
  comments, xrefs and `H` work there as in the listing.
- `N` on a local, parameter or temporary in the pseudocode renames it for
  that function. The name is saved as an `lvar` annotation, which
  `spelunk -p` applies as well.
- `X` lists data references (reads, writes and address-taking) next to
  calls, jumps and string references.
- IDA key bindings: `N` rename, `;` and `:` comments, `X` xrefs, `Tab` to
  switch between disassembly and pseudocode, `H` number base, `Ctrl+P` /
  `Ctrl+L` choosers, `Alt+M` / `Ctrl+M` marks.
- An IDA-shaped listing with `proc near` / `endp`, `loc_` labels and code
  xrefs. Renames and comments persist to the annotations database.

## Robustness

- The ELF, REL, PE and Mach-O loaders are hardened against malformed input
  and covered by fuzz targets and sanitizer jobs.

## Known Gaps

- AVX-512, SHA-NI and AVX-VNNI are not decoded yet.
- GCC rejects some vector pseudo-C that mixes `__m128` and `__m128i`; Clang
  accepts it.
- A local array indexed in a loop can render as an invalid
  `((void*)...)[0]` store.
- A few very large functions still leave blocks unstructured
  (`STRUCTURER_FAIL` markers) or take tens of seconds to render.
- Packaged builds are Linux x86-64 only.
