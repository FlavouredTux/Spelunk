# Spelunk 2.0.1

A small release for agents and other scripted callers, and the first with a
macOS build.

## Command Line

- `--strings --json` emits one record per string: its address, text and the
  addresses that reference it.
- `--refs-to` reports a direct reference at the call instruction itself, one
  row per call site, instead of at the start of the calling function.

## Builds

- macOS on Apple Silicon (15 or later) is packaged with each release. The C++
  runtime it was built with ships in `lib/` next to the binary.
- The sources build with libc++ as well as libstdc++.

## Downloads

- `spelunk-2.0.1-linux-x86_64.tar.gz`: the CLI for Linux on x86-64.
- `spelunk-2.0.1-macos-arm64.tar.gz`: the CLI for macOS 15 or later on Apple
  Silicon. Keep `lib/` next to `spelunk`. The binary is not notarized; if
  macOS refuses to open it, run
  `xattr -dr com.apple.quarantine spelunk-2.0.1-macos-arm64`.
