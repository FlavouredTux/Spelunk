# Spelunk 2.0.2

A fix for callers that trust `--callees` to be complete.

## Command Line

- `--callees` reports a tail jump to a function Spelunk discovered without a
  symbol, as on stripped images. Before, a function ending in such a jump
  could come back with no callees while still claiming a complete extent.

## Downloads

- `spelunk-2.0.2-linux-x86_64.tar.gz`: the CLI for Linux on x86-64.
- `spelunk-2.0.2-macos-arm64.tar.gz`: the CLI for macOS 15 or later on Apple
  Silicon. Keep `lib/` next to `spelunk`. The binary is not notarized; if
  macOS refuses to open it, run
  `xattr -dr com.apple.quarantine spelunk-2.0.2-macos-arm64`.
